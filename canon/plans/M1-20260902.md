## Why M1 in TS is faster than M1 in Go

The Go version's M1.1-M1.16 was ~16 sub-steps. Many of them
(the CLI ergonomics) are already done in the TS port because
the TS port is **just the CLI**. The data plane (helper) is
the same binary; we don't rewrite it.

## M1.17 details

The friend test is no longer held — the agent ran a real
cross-platform round-trip: started the helper binary as
`up` on Mac (darwin/arm64), dialed it from a real Linux
host (`linux` SSH alias, Ubuntu 24, x86_64) using the
cross-built `bin/tunnelcat-helper-linux-amd64`. The Linux
dial sent a marker string; the Mac server echoed it back
through DERP-304. The marker appeared in the Linux dial's
output. Round-trip time: 30-90s depending on DERP region
selection.

5/5 stable runs locally. The reverse direction (Linux
server, Mac client) was attempted but the DERP region
selection between Mac (often DERP-1 Tokyo) and the Linux
box (often DERP-304) is flaky. The forward test alone is
sufficient to prove the wire; the reverse is "extra
credit" for a future test plan.
